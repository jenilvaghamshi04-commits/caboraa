# caboraa Cab Booking Demo

This is a responsive static website built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with:

```bash
npx serve .
```

## Deploy on Render

1. Push this folder to a GitHub repository.
2. In Render, create a new **Static Site**.
3. Connect the repository.
4. Leave the build command empty.
5. Set the publish directory to `.`.
6. Deploy the site.

The booking buttons use phone and WhatsApp links for `8866305165`.
